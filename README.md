## 🧩 My Approach

For each problem, I try to follow this process:

```text
Understand the Problem
        ↓
Identify Constraints
        ↓
Find the Brute Force Approach
        ↓
Analyze Time & Space Complexity
        ↓
Identify an Optimized Pattern
        ↓
Implement the Solution
        ↓
Test Edge Cases
        ↓
Submit & Analyze Performance
```

The goal is not simply to get an accepted submission, but to understand **why the solution works and how it can be improved**.
